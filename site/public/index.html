WGuard — античит с коробки

Каждый запуск сайта и лаунчера сопровождается проверкой целостности (сплеш выше). Серверные проверки нельзя обойти модификацией клиента: все команды ревалидируются на сервере.

HWID + сессии

Привязка входа к аппаратному ID. Короткие токены с refresh.

Packet-limit

Аномальные скачки трафика блокируются, log пишется в audit.

Server-side validation

Ни одно решение (лечение, выдача, перемещение) не принимается от клиента напрямую.

Установка

Лаунчер — рекомендуемый способ запуска. Для выделенных серверов есть Docker-пакет.

1. Лаунчер

cd launcher && npm install && npm run dev

2. Сайт локально

cd site && npm install && npm start → :4000

3. Сервер (Docker)

cd docker && EULA=true docker compose up -d
