# War Project

Монорепозиторий модов для Minecraft (Forge 1.20.1).

## Структура

```
warproject-okop/
├── okop/               # Мод "Окоп" — траншейная фортификация
│   ├── build.gradle
│   ├── settings.gradle
│   ├── gradle.properties
│   ├── src/
│   └── tools/
├── <следующий-мод>/    # Следующие моды добавлять сюда
│   ├── build.gradle
│   └── src/
└── README.md
```

## Моды

### 🏗️ Okop (Траншейная фортификация)

Реалистичная фортификация окопов: опорные балки, маскировочные сетки, мешки с песком, колючая проволока, амбразуры, траншейные фонари и многое другое.

**Быстрый старт:**
```bash
cd okop
python tools/generate_textures.py   # Генерация текстур
gradle wrapper --gradle-version 8.1.1
./gradlew runClient                  # Запуск клиента
```

## Добавление нового мода

1. Создайте папку с именем мода в корне репозитория
2. Инициализируйте Forge/Fabric проект внутри
3. Добавьте описание в этот README
